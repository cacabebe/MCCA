# MCCA

基于全新架构的 交错战线 CrossCore 小助手。图像技术 + 模拟控制，解放双手！  
由 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 强力驱动！

## 功能介绍

目前已有的功能：

1. 启动游戏
2. 每日免费礼包
3. 每日探索(只使用自然回复的燃料)
4. 模拟军演(只打第一个，次数耗尽为止)
5. 基建(换班+好友换抽)
6. 周本(支持第一关(45微晶)、第五关(120微晶)。需提前配好一队)
7. 领取奖励(邮箱+每日+通行证)
8. 关闭游戏
9. 推主线（普通或困难主线当前进度，自动跳剧情、保持原队伍开战、结算后继续）
10. 刷主线（自动定位普通 7-8「传说之外」，持续扫荡至燃料不足）
11. 每周商店购买（万物贸易所和模拟军演指定商品）

### 每周商店购买

重新打开助手，在任务列表勾选「每周商店购买」。任务依次购买以下商品，按各商店的余额和库存选择可买数量，售罄自动跳过，最后回到首页。

- 万物贸易所 · 异星灰域：传说星尘券、罕见星尘券、构建蓝图、高纯硅化剂、进化之息。
- 万物贸易所 · 罕见星尘区：构建蓝图、限量微晶。
- 模拟军演 · 商店兑换：任意属性的传说星尘、传说星尘券、构建蓝图、罕见星尘券。

### 刷主线 7-8

重新打开助手，在任务列表勾选“刷主线”，在“刷主线关卡选择”中选择“7-8 传说之外（普通）”（目前唯一选项）。从游戏首页、出击选择页或第 7 章普通地图开始，脚本进入第 7 章，选择“米德加尔特”下的“7-8 传说之外”并扫荡。找不到地区时向左上拖动地图，最多尝试 3 次；仍未找到则超时停止。请提前通关并解锁该关卡扫荡，不要同时勾选“推主线”。

每批自动选择当前燃料可承担的 1–10 次，结算后继续扫荡，直到不足 1 次时停止。不购买或使用燃料道具，加成提示选择“不使用”。此任务拥有独立的次数和燃料处理，不受“每日探索”的手动次数及燃料选项影响。

2026-10-22 已实机修复并验证：点击第7章缩略卡后，继续点击展开页的“虚拟场域”进入地图；扫荡结算点击左上“扫荡成功”标题退出。从首页完成导航、向左上拖动找地区、选择7-8，并连续完成两批扫荡。实机验证将每批限制为1次，正常运行仍为每批最多10次；燃料不足停止另有离线回归覆盖。

### 推主线

重新打开助手后，在任务列表选择“推主线”。先手动打开普通或困难主线当前进度页，配好队伍并开启自动战斗；脚本保持当前难度，也可从进行中的剧情或战斗接续。只勾选该任务运行，避免其他任务把游戏带离主线。关卡的“新”标记使用图像匹配，避免小字 OCR 漏识别。

燃料不足或战败时停止，不购买或使用燃料。未识别到可操作界面（包括单场战斗超过 10 分钟）会超时停止。当前区域完成后尝试下一页，无新关卡会停止；跨章节特殊解锁界面需手动处理后重启任务。

也可使用项目自带 Python 独立运行（不要与图形助手同时控制游戏）：

```powershell
.\python\python.exe scripts\push_main.py
# 在另一个终端停止，或在运行终端按 Ctrl+C
.\python\python.exe scripts\push_main.py --stop
```

默认连接助手配置的 ADB 设备，可用 `--serial 127.0.0.1:16416` 指定设备。运行记录与结束截图保存在 `debug/main-story/`。

独立运行脚本还会每 3 秒比较画面；连续约 10 秒基本不变时，尝试点击两次上方中央空白处。两次恢复尝试至少间隔 60 秒，每次运行最多尝试 3 轮，恢复前截图保存在运行目录。此兜底仅用于独立脚本，图形助手仍使用界面识别流程。

## 使用说明

下载地址：<https://github.com/MaaXYZ/MCCA/releases>
1. MuMu模拟器需要关闭模拟器设置中的“后台挂机时保活运行”
2. 运行过程MaaPiCli窗口出现红字是正常的
3. 模拟器不能有中文路径
4. 模拟器窗口大小要16:9，最好建议是使用720p分辨率
5. 运行卡住请将debug文件夹中的maa.log发出来，并附带出错时的游戏截图

### Windows

- 对于绝大部分用户，请下载 `MCCA-win-x86_64-vXXX.zip`
- 若确定自己的电脑是 arm 架构，请下载 `MCCA-win-aarch64-vXXX.zip`
- 解压后运行 `MaaPiCli.exe` 即可


### macOS

- 若使用 Intel 处理器，请下载 `MCCA-macos-x86_64-vXXX.zip`
- 若使用 M1, M2 等 arm 处理器，请下载 `MCCA-macos-aarch64-vXXX.zip`
- 使用方式：

  ```bash
  chmod a+x MaaPiCli
  ./MaaPiCli
  ```

### Linux

~~用 Linux 的大佬应该不需要我教~~

## 图形化界面

- 如果需要使用图形化界面，请下载 `MCCA-win-x86_64-with-gui-vXXX.zip`，目前只支持Windows
- 图形化界面需要.NET8运行库，请自行安装
- 解压后运行`MFAWPF.exe`即可
- 本GUI由社区大佬[SweetSmellFox](https://github.com/SweetSmellFox)编写，相关项目见[MFAWPF](https://github.com/SweetSmellFox/MFAWPF)

## 其他说明

- 添加 `-d` 参数可跳过交互直接运行任务，如 `./MaaPiCli.exe -d`
- 反馈问题请附上日志文件 `debug/maa.log`，谢谢！


## How to build

**如果你要编译源码才看这节，否则直接 [下载](https://github.com/MaaXYZ/MCCA/releases) 即可**

0. 完整克隆本项目及子项目

    ```bash
    git clone --recursive https://github.com/MaaXYZ/MCCA.git
    ```

1. 下载 MaaFramework 的 [Release 包](https://github.com/MaaXYZ/MaaFramework/releases)，解压到 `deps` 文件夹中
2. 安装

    ```python
    python ./install.py
    ```

生成的二进制及相关资源文件在 `install` 目录下
